ORXA AppIn Development
ORXA

A controller built for
the games you play.

The ORXA App is being built as a universal smartphone controller for compatible games. Install once. Use it across different ORXA-enabled games.

Planned capabilities

  • Optimized native controller experience
  • Haptic feedback
  • Gyroscope and motion controls
  • Quick reconnection and player profiles
  • Dynamic controller layouts
  • Low-latency architecture

Performance targets are under development; no latency figures are claimed.

  • Real-time input
